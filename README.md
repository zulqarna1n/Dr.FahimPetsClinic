# 🐾 Dr. Fahim Pet Clinic Website

A modern, premium, fully responsive veterinary clinic website built using **HTML5, CSS3, and Vanilla JavaScript**.

Designed for GitHub Pages deployment with no backend requirements.

---

# 📌 Project Overview

Dr. Fahim Pet Clinic Website is a professional veterinary hospital website designed to provide:

- Clinic information
- Veterinary services
- Pet gallery
- Doctor profile
- Contact information
- WhatsApp appointment booking

The website is fast, responsive, accessible, and optimized for static hosting.

# 📱 WhatsApp Appointment System

The appointment system works without a backend.

When a user submits the form:

1. JavaScript collects the information.
2. Creates a formatted WhatsApp message.
3. Opens WhatsApp with the appointment request.

Collected information:

- Owner Name
- Phone Number
- Pet Name
- Pet Type
- Breed
- Age
- Service
- Preferred Date
- Preferred Time
- Additional Notes

No information is stored.

# 🌐 Deploy On GitHub Pages

## Step 1

Create a GitHub repository:

Example:

  
Dr-Fahim-Pet-Clinic
  

---

## Step 2

Upload all project files.

Your repository should contain:

  
index.html
css/
js/
assets/
  

---

## Step 3

Open:

  
Repository Settings
  

Go to:

  
Pages
  

Select:

  
Deploy from branch
  

Choose:

  
main
  

Folder:

  
/root
  

Save.

---

## Step 4

GitHub will generate your website link:

Example:

  
https://username.github.io/Dr-Fahim-Pet-Clinic/
